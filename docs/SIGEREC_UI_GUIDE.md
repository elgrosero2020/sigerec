# SIGEREC UI Guide

## Versión 1.3.4 — Navegación Institucional

### Objetivo
Unificar la navegación del sistema para que SIGEREC se perciba como una plataforma institucional, no como un conjunto de páginas aisladas.

### Componentes incorporados
- `templates/components/navbar.html`: cabecera institucional, menú principal, estado de sesión y menú de usuario.
- `templates/components/breadcrumb.html`: ruta de navegación reutilizable.
- `static/css/sigerec-ui.css`: reglas visuales del sistema de diseño SIGEREC.

### Convenciones visuales
- La navegación usa verde institucional profundo como color base.
- Los estados de usuario se muestran como elementos compactos, no como texto suelto.
- Las rutas activas se resaltan con fondo translúcido.
- El breadcrumb aparece en páginas internas para reforzar orientación.

### Criterio de diseño
Cada pantalla debe sentirse parte del mismo producto. La navegación debe comunicar confianza, orden institucional y facilidad de uso.

# SIGEREC — Roadmap

## v1.0 — Sistema base

Objetivo: construir el flujo principal del sistema.

Incluye:

- Registro de vecinos.
- Login y logout.
- Roles básicos.
- Reporte de reclamos.
- Consulta por número de seguimiento.
- Dashboard inicial.
- Cambio de estado.

## v1.1 — GPS y mapas

Objetivo: mejorar la precisión territorial de los reclamos.

Incluye:

- Captura de latitud y longitud.
- Botón “Usar mi ubicación actual”.
- Enlace a Google Maps.
- Mapa embebido con OpenStreetMap / Leaflet.

## v1.2 — Seguimiento y Centro de Reportes

Objetivo: fortalecer la gestión institucional.

Incluye:

- Detalle del reclamo.
- Línea de tiempo.
- Historial visible.
- Centro de Reportes.
- Exportación CSV.
- Exportación Excel institucional.

## v1.3 — Design System y consistencia visual

Objetivo: convertir las páginas en un producto visualmente coherente.

Incluye:

- Componentes reutilizables.
- Navegación institucional.
- Breadcrumb.
- Dashboard premium.
- Consulta premium.
- Formularios premium.
- Consistencia visual entre pantallas.

## v1.4 — PDF institucional

Objetivo: generar informes formales para presentación o entrega institucional.

Planeado:

- Exportación PDF.
- Encabezado institucional.
- Resumen ejecutivo.
- Tabla de reclamos.
- Pie de página.
- Numeración.

## v1.5 — Centro de Operaciones

Objetivo: crear una pantalla de monitoreo operativo para presidentes.

Planeado:

- Reclamos urgentes.
- Alertas.
- Actividad reciente.
- Mapa operativo.
- Indicadores clave.

## v1.6 — Optimización y seguridad

Objetivo: preparar el sistema para entrega final.

Planeado:

- Revisión de permisos.
- Limpieza de vistas.
- Optimización de consultas.
- Manejo de errores.
- Validaciones.
- QA final.

## v2.0 — Plataforma multi-barrio

Objetivo: evolucionar el MVP hacia una solución institucional más amplia.

Planeado:

- Gestión de múltiples juntas vecinales.
- Administración central.
- Estadísticas por barrio.
- Filtros territoriales.
- Roles avanzados.
- Base de datos PostgreSQL.

## v3.0 — Integración municipal

Objetivo: preparar SIGEREC para integración con procesos municipales.

Planeado:

- API.
- Notificaciones.
- Derivación formal a unidades municipales.
- Panel de seguimiento institucional.
- Auditoría avanzada.
